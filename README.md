# AI + Design Career Kit

Status: standalone post-course student resource  
Entry file: `index.html`  
Primary audience: DESN 374 students after Canvas access ends
GitHub Pages URL: `https://sicxz.github.io/ai-design-career-kit/`

This folder contains a static career guide that helps students translate DESN 374 work into resume, LinkedIn/about, portfolio, and interview language.

## Files

- `index.html` - complete student-facing guide and all copy-ready content.
- `foundry.css` - copied Foundry design system tokens and reusable classes.
- `styles.css` - career-guide layout and content styling built on Foundry.
- `script.js` - progressive enhancement for copy buttons and active section navigation.
- `verification.md` - manual verification checklist and results.

## Use

Open `index.html` directly in a browser, or serve this folder from any static host.

The guide is not Canvas content. It does not fetch Canvas data, use an API key, save student data, or generate personalized output.

## Editing Rules

- Keep all required content visible in `index.html`.
- JavaScript may improve usability, but the guide must remain usable with JavaScript disabled.
- Use truthful student language: worked with, compared, explored, documented, evaluated, revised.
- Do not imply professional expertise unless a student has evidence beyond coursework.
- Keep examples bracketed where students must customize.

## Verification

Before sharing the page, complete `verification.md`.
